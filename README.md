# HR 灵魂拷问

一个帮助 HR 和业务负责人把方案想清楚的 AI 技能。通过逐轮提问，找出方案中的关键假设、证据缺口、未决事项和隐藏取舍，最后形成一份人力决策摘要。

## 适合什么时候用

- 方案已有雏形，希望有人挑战一下逻辑。
- 问题描述很模糊，需要先明确目标和决策。
- 团队对原因或方向存在分歧，需要梳理事实与假设。
- 招聘、培养、组织调整等方案涉及多个相互依赖的决策。

简单事实查询通常无需调用本技能。

## 怎么使用

技能本体是 [SKILL.md](SKILL.md)，无须额外脚本或依赖文件。

**在支持技能的 AI 工具中：**按工具的技能导入方式安装本仓库，或将 `SKILL.md` 放入名为 `hr-grilling` 的技能目录，然后明确调用 `hr-grilling`。具体导入位置以所用工具为准。

```text
hr-grilling/
└── SKILL.md
```

**在普通 AI 对话中：**上传 `SKILL.md`，或复制其正文，并发送：

> 请阅读这份技能文件，按 HR 灵魂拷问的方法审视我接下来提供的方案。先使用已有材料，每轮最多问三个相互独立的问题，最后给出人力决策摘要。

普通对话方式是让 AI 按文件中的指令工作，后续新对话需要重新提供文件或上下文。

## 调用示例

> 请用 HR 灵魂拷问审视我的新人培养方案。目标是缩短新人独立上岗周期。下面是现状和方案，请先找出关键假设与待决策事项。

> 我觉得业绩下降是销售能力不足，准备增加培训。请挑战这个判断，先检查有哪些证据支持它，还有哪些替代解释。

> 请对这份组织调整方案做压力测试，重点看目标是否一致、资源配置是否有依据，以及哪些决策需要负责人拍板。

材料可以不完整，不需要先填写固定问卷。最好说明目标、现状、当前方案和已知约束，并附上能支持判断的资料。

## 会得到什么

默认用中文交流，每轮最多提出三个相互独立的问题。AI 会先查找当前环境中可获取的证据，并明确区分事实、假设和人的决策；风险较高的分支会接受更深入的压力测试。

当重要决策和信息缺口已经明确、继续追问难以改变判断时，结束访谈，输出包含目标、事实、假设、已作决策、未决事项、所需证据、风险与取舍、验证方式的人力决策摘要。

## 使用边界

本技能提供决策澄清与访谈方法。具体招聘、培养、组织设计、员工关系等专业背景，以及公司制度和实际业务数据，需要由使用者、相关领域技能或可访问的资料提供。

管理和价值选择由责任人作出。文件不能自动赋予 AI 访问公司系统的权限；无法获取的证据会明确列为缺口。

当前为 v0.9 中文版，建议结合真实案例使用并记录反馈。文件结构检查不代表已验证所有业务场景的效果。
