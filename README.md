# hr-grilling v0.9 交接包

这是可迁移到新账号继续开发的项目资料包。

## 文件

- `SKILL.md`：冻结候选版 v0.9 Skill 正文。
- `DESIGN_DECISIONS.md`：可核实的选择、接口约定和仍待确认事项。
- `PROJECT_CONTEXT.md`：目标、架构、Dogfooding 背景、下一步开发顺序。
- `README.md`：本说明与可复制的续接提示。

## 新账号续接提示

将本目录中的三个项目文件提供给新账号，并发送：

> 我正在继续开发一个 HRBP Grilling Skill（HRBP 灵魂拷问技能）。请先阅读 SKILL.md、DESIGN_DECISIONS.md、PROJECT_CONTEXT.md。当前版本是 v0.9 冻结候选版，请不要重新设计已经确认的架构。先向我确认 DESIGN_DECISIONS.md 中员工培养智能体 Dogfooding 的三个开放决策；确认后，直接用 v0.9 对员工培养智能体方案做真实案例压力测试，记录具体行为证据和失效点。只有在真实案例证明存在可复用的通用推理缺陷时才修改 Skill；领域规则留在对应的 Domain Skill。原方案附件若需要全文，请我重新提供。

## 迁移方式

解压 `hr-grilling-handoff.zip`，把整个 `hr-grilling-handoff` 文件夹作为附件或项目资料提供给新账号。不要只传 README；完整 Skill 和决策记录都在包内。
